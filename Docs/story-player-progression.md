# Story and player progression

Story #6 defines the first progression slice for Chromalock.

## Level contract

Each level introduces one new cooperative idea:

1. **The First Tint** — one shared pastel target and one locked door.
2. **Split Signals** — each player sees a different station clue.
3. **The Shared Spark** — the target changes after mistakes and the timer matters.

## Player feedback

- Level completion adds points to the shared score.
- Completing level two adds an avatar accent.
- Completing level three reveals the player's Spark stage.
- The level number and objective remain visible so progression is understandable without visual clutter.
